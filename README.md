# ValoraIQ

Appraisal-grade CMA intelligence for real estate agents, brokers, teams, and appraisers.

## What this build includes

- Agent/Appraiser/Hybrid positioning
- Demo data mode
- Agent command dashboard
- Active / Pending / Expired market intelligence
- Seller presentation builder
- Seller net sheet and renovation ROI scenario
- Appraiser workfile support export
- Internal analysis summary export
- Site / land value support
- Comp ranking with distance, garage, basement, pool, GLA, site, age, Q/C, and recency
- Restart / clear-all workflow
- Editable narratives and report outputs
- First-use professional disclaimer
- Optional animated ValoraIQ assistant that can be disabled

## Local development

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Use the default Vite settings.
4. Deploy.

## Professional-use disclaimer

ValoraIQ organizes market evidence and pricing support. It is not an appraisal replacement. Agents and brokers should present outputs as CMA/pricing support. Appraisal conclusions remain the responsibility of a licensed appraiser under an appropriate scope of work.

## Privacy

Browser saves use localStorage on the user device. Exported JSON/report files may contain addresses and transaction details and should be handled like confidential real estate workfile material.
